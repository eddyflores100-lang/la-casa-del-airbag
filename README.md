# La Casa del Airbag — Web ecosystem

Repositorio de trabajo para las marcas **La Casa del Airbag**, **SRS EXPERT** y **SRS LAB**.

## Estructura
- `sites/srs-expert/index.html`: HTML publicado de SRS EXPERT, exportado desde WebsitePublisher.
- `sites/srs-lab/index.html`: HTML publicado de SRS LAB, exportado desde WebsitePublisher.
- `assets/`: recursos gráficos y tipográficos originales exportados de ambos proyectos.
- `assets-manifest.json`: URLs de origen y rutas de cada recurso.

## Marcas y dirección visual
- **SRS EXPERT:** azul marino profundo, azul eléctrico, acero/plata y blanco.
- **SRS LAB:** grafito, naranja eléctrico y blanco.

## Nota de exportación
Los HTML son copias de los documentos que estaban publicados al exportar. Los recursos se conservan en `assets/<marca>/`; el HTML original sigue apuntando a las URLs CDN del hosting para preservar su comportamiento publicado. No contiene credenciales ni claves API.
